# Reusable 3D library

Meshes for the HQ. Nothing here is bought, generated by a paid service, or copied from another game. Fony's base mesh is the CC0 Quaternius free Standard pack; see `fony/README.md`.

| Asset | Scene | What it is |
|---|---|---|
| Quarter pipe | `quarter_pipe/quarter_pipe.tscn` | One concrete quarter with a deck, metal coping, and flat graffiti panels |
| Fony | `fony/human/fony_human.gltf` | CC0 human skater, rebound onto the trick skeleton. See `fony/README.md` |

Each asset folder has its own note for size, pivot, collision, and how to place another copy.
