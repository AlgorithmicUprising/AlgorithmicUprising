# Algorithmic Uprising

Public code workspace for Algorithmic Uprising experiments. The Punk Arcade project lives under [`arcade/`](arcade/README.md) and is developed on the `arcade` branch.

## Project boundaries

The production website, music masters, and the band's protected visual identities are **not** distributed by this repository. Arcade game code is intended for MIT licensing; starter art may be CC BY 4.0, while AU branding remains reserved. Consult per-project licenses before reuse.
