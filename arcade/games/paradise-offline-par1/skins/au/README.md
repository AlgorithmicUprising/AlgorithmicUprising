# Paradise Offline · AU skin art

## Source and usage

All four source images were generated for this project with OpenAI image generation on 2026-11-22. The project owner authorized their use in the Paradise Offline PAR-3 prototype and its GitHub Pages preview. No third-party imagery, logos, recordings, or Zero likenesses are included. The game's source-code license does not apply to these artwork files.

Original PNGs are retained in `source/`. The smaller WebP files in `assets/` are the runtime derivatives loaded by `skin.json`.

## Art direction and approved variation

Warm, hand-painted cel shading and visible print grain place the playable homestead against an amber sunrise and distant corporate skyline. The yard, coop, well, garden, and workbench remain readable at the camera scale. The portrait plate reframes the same locations vertically; it is not a separate setting. Keep the character and prop sheets free of added branding. The generated sheets are source art, not pre-cut runtime atlases; frame selection stays in the game renderer.
