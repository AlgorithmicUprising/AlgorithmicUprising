# Paradise Offline · PAR-2

The five-day local campaign built on the Uprising Arcade host. The component ID remains provisional; it has no permanent cabinet slot or public score submission.

## Play

From the Arcade workspace, run `npm install`, `npm run build`, then serve `arcade/` over HTTP and open `games/paradise-offline-par1/demo/`. Choose Ranked Scenario or Practice; both use the deterministic seed 420521. Plan Live, Edited Update or Offline days, select up to three Live camera views, resolve the tomato event and storm choices, and manage three household work slots per day.

The week carries home, coop, garden, well, energy, boundary integrity, cash, boards, feed, water, food and audience. Feed, repair, gardening, drawing water, cooking, editing, moderation and rest have visible resource costs and outcomes. The five-day report shows each day’s before/after changes, schedule, jobs, event consequences, score, seed, mode and score version.

## Controls

- Keyboard: Enter/Space confirms the focused choice; arrow keys move through the visible buttons. The letter/number shortcuts are printed on applicable controls. Escape pauses.
- Gamepad: A confirms the focused choice; D-pad or left stick moves through visible choices; B uses the stage’s safe default; Start pauses.
- Touch/mouse: tap a visible choice.
- Live/Edited/Offline work remains local. No live chat, remote random events or game-specific network calls are made.

## Phase boundary

PAR-2 deliberately keeps the shared procedural yard and no music. Final character/environment art, scene plates and gameplay animations are PAR-3; music and sound are PAR-4; account/leaderboard handoff is PAR-5. A local Zero Score target of 72/100 is provisional and awaits PAR-6 balance work.
