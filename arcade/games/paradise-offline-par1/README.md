# Paradise Offline · PAR-1

A provisional one-day vertical slice for the Uprising Arcade. It uses the existing Arcade GameAPI and host shell. It is not assigned a permanent cartridge slot or public game ID.

## Play the slice

Run `npm install`, `npm run build`, then serve the `arcade/` directory over HTTP and open `games/paradise-offline-par1/demo/`. Select Live or Offline, choose at least one public yard camera for Live, then spend up to three work slots.

Feed the hens, repair the coop, rest, or finish early. A fixed fictional viewer tip can reduce the next feed or repair energy cost. A one-time optional sponsor offer shows every term before acceptance. Accepting spends a work slot and energy, adds cash and a roof board, and briefly shows a generic private-room cutaway chosen by the player. The private room stays outside all yard camera zones.

## Prototype limits

All scene graphics are procedural placeholders; no final character art, scene renders, music, or voice lines are included. The one-day loop is the only implemented chapter. No live chat, remote data, random events, account score submission, or leaderboard eligibility is enabled. Results are local and marked as practice so the host suppresses score submission.
