# Paradise Offline · PAR-3

The five-day local campaign built on the Uprising Arcade host. PAR-3 adds reusable AU skin art, responsive landscape and portrait scene plates, actor and prop sprites, camera coverage overlays, and reduced-motion support. The component ID remains provisional; it has no permanent cabinet slot or public score submission.

## Play

From the Arcade workspace, run `npm install`, `npm run build`, then serve `arcade/` over HTTP and open `games/paradise-offline-par1/demo/`. The demo loads the AU scene skin from the local `skins/au/` directory. Choose Ranked Scenario or Practice; both use the deterministic seed 420521. Plan Live, Edited Update or Offline days, select up to three Live camera views, resolve the tomato event and storm choices, and manage three household work slots per day.

The week carries home, coop, garden, well, energy, boundary integrity, cash, boards, feed, water, food and audience. Feed, repair, gardening, drawing water, cooking, editing, moderation and rest have visible resource costs and outcomes. The five-day report shows each day’s before/after changes, schedule, jobs, event consequences, score, seed, mode and score version.

## Controls

- Keyboard: Enter/Space confirms the focused choice; arrow keys move through the visible buttons. The letter/number shortcuts are printed on applicable controls. Escape pauses.
- Gamepad: A confirms the focused choice; D-pad or left stick moves through visible choices; B uses the stage’s safe default; Start pauses.
- Touch/mouse: tap a visible choice.
- Live/Edited/Offline work remains local. No live chat, remote random events or game-specific network calls are made.

PAR-3 includes scene art and job-state sprites. Music and sound are PAR-4; account/leaderboard handoff is PAR-5. A local Zero Score target of 72/100 is provisional and awaits PAR-6 balance work.
